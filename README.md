# Portal de Suporte e Compras

Este é um sistema corporativo completo para gestão de chamados de TI, solicitações de compras, agendamentos e base de conhecimento.

## 🚀 Como começar

1.  **Acesse o sistema:** Realize seu cadastro na página `/signup`.
2.  **Aguarde aprovação:** Sua conta precisará ser ativada por um administrador.
3.  **Explore as funções:** Uma vez logado, você poderá abrir chamados, consultar manuais e reservar salas.

## 🛠️ Tecnologias Utilizadas

- **Next.js 15** - Framework React para o frontend.
- **Firebase** - Banco de dados (Firestore) e Autenticação.
- **Tailwind CSS** - Estilização moderna e responsiva.
- **ShadCN UI** - Componentes de interface de alta qualidade.
- **Vercel Blob** - Armazenamento de arquivos e anexos.
